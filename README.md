# Demil Bajracharya — Developer Portfolio

A responsive personal developer portfolio for **Demil Bajracharya**, a BCA student and aspiring software developer based in Kathmandu, Nepal.

The site presents Demil's background, learning journey, technologies, selected projects, learning notes, GitHub status, and contact information through a dark editorial interface with lime-green accents.

## Live site

https://demilbajracharya.com.np/

## Features

- Responsive portfolio layout for desktop, tablet, and mobile screens
- Accessible navigation with smooth section scrolling and keyboard focus states
- About, technologies, journey, projects, learning notes, GitHub, and contact sections
- FocusFlow project link and honest placeholder states for work still in progress
- Contact form with client-side validation and an email-link alternative
- SEO metadata, Open Graph metadata, Twitter card metadata, and focused meta keywords
- Reduced-motion support for visitors who prefer less animation

## Technology

- React
- TypeScript
- Vite
- Lucide React
- CSS custom properties and responsive media queries

## Getting started

### Prerequisites

- Node.js 18 or newer
- npm

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

The development server runs on port `3000`.

### Create a production build

```bash
npm run build
```

The production files are generated in `dist/`.

### Preview the production build

```bash
npm run preview
```
